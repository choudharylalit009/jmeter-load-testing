# JMeter Performance & Load Testing

## 📌 Overview

This project demonstrates performance and load testing using Apache JMeter.
The test plan is designed to simulate concurrent users, execute application
requests, and analyze system performance using key performance metrics.

The project includes a JMeter test plan, performance results, an HTML report,
CSV-based test results, and response-time visualization.

---

## 🛠️ Tools & Technologies

- Apache JMeter
- Performance Testing
- Load Testing
- Stress Testing
- HTTP/API Testing
- CSV Data Analysis
- HTML Reporting
